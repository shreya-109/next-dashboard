# Learning Dashboard

A modern and responsive learning dashboard built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Supabase.

## Features

* Responsive dashboard layout
* Sidebar navigation
* Welcome hero section
* Course progress tracking
* Learning activity visualization
* Smooth UI animations
* Supabase integration
* Deployed on Vercel

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Supabase
* Vercel

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/shreya-109/next-dashboard.git
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

4. Open http://localhost:3000 in your browser.
